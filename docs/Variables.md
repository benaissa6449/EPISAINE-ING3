# Gitlab variables

Settings -> CI/CD -> Variables

| Key | Description |
| - | - |
| Host_CICD | CI/CD VM IP Address |
| Host_Datalake | Datalake VM IP Address |
| Host_ETL | ETL VM IP Address |
| Host_ORCH | ORCH VM IP Address |
| Host_PSQL | PSQL VM IP Address |
| SSH_PRIVATE_KEY | CI/CD VM SSH Private Key |
| USER | VM User name |
| USER_PASSWORD | VM User password |
